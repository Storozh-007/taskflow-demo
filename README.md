# TaskFlow

Навчальний PWA-застосунок: Vue 3, Framework7 та Vite.
Практична робота №4 / КП 2/6: Реактивні форми, створення та редагування завдань у TaskFlow.

Універсальна форма `TaskForm.vue`, валідація введених даних, двостороннє зв'язування `v-model.trim`, обчислювані помилки `computed()`, попередній перегляд у реальному часі, збереження нових завдань та редагування наявних через Props та Emits. Картки завдань і статистика на сторінках `HomePage` та `TasksPage` оновлюються реактивно через спільний стан `taskState`.

Попередні версії збережено тегами `kp2-3-complete`, `kp2-4-complete`, `kp2-5-complete`.

Застосунок: https://taskflow-demo.kpidanil.workers.dev

Репозиторій: https://github.com/Storozh-007/taskflow-demo

## Що реалізовано (КП 2/6)

1. **Універсальний компонент форми `src/components/TaskForm.vue`**:
   - Робота у двох режимах: створення нового завдання (`task=null`) та редагування наявного (`task=Object`).
   - Локальна копія стану у `reactive()` — оригінальні дані картки не мутуються до підтвердження збереження (коректне скасування).
   - Двостороннє зв'язування `v-model.trim` для текстових полів (`title`, `description`).
   - Попередній перегляд у реальному часі (`aria-live="polite"`).
   - Блокування стандартної поведінки форми `@submit.prevent="submitForm"` та вимкнення браузерної валідації `novalidate`.
   - Події `save` (передає валідні дані форми) та `cancel` (скасовує дію).

2. **Розширення реактивного сховища `src/store/tasks.js`**:
   - `addTask(data)`: додає нове завдання з автоматичним обчисленням `id = max(id) + 1`.
   - `updateTask({ id, ...data })`: оновлює існуюче завдання, гарантовано зберігаючи його `id`.
   - `normalizeTaskData`: багаторівнева перевірка довжини назви (3–80 симв.), опису (до 300 симв.), статусів, пріоритетів, категорій та коректності календарної дати.

3. **Оновлення картки `src/components/TaskCard.vue`**:
   - Новий prop `editable`: керує відображенням кнопки «Редагувати». На «Головній» картки залишаються компактними без зайвих кнопок, а на сторінці «Мої завдання» вмикається можливість редагування.
   - Генерація події `edit` з передачею `task.id`.
   - Відображення бейджа категорії завдання (`tf4-category-badge`).

4. **Інтеграція у сторінку `src/pages/TasksPage.vue`**:
   - Кнопка «+ Додати завдання» для відкриття форми створення.
   - Обробка події `edit` від карток — відкриття форми редагування з заповненими полями.
   - Плавне прокручування до форми `scrollToForm()` з використанням `nextTick()`.
   - Інформаційні повідомлення про результат збереження (`tf4-feedback`).
   - Автоматичне скидання фільтрів та пошуку після збереження завдання.

5. **Виконані додаткові завдання (1–7)**:
   - **Завдання 1:** Поле «Категорія» (навчання, робота, особисте) у формі та бейдж у картці.
   - **Завдання 2:** Перевірка, що дата нового завдання не є минулою; для старих демонстраційних завдань дозволено зберегти їхню первісну дату без помилки.
   - **Завдання 3:** Лічильник залишку символів для назви (80 - length) та опису (300 - length).
   - **Завдання 4:** Кнопка «Очистити форму» у режимі створення.
   - **Завдання 5:** Візуальне позначення обов'язкових полів (`*`) та покращена доступність (`aria-describedby`, `aria-invalid`, `role="alert"`).
   - **Завдання 6:** Поле живого пошуку за назвою без потреби натискання окремих кнопок.
   - **Завдання 7:** Перевірка унікальності назви завдання без урахування регістру (Case-insensitive).

## Межі та збереження даних

Зміни зберігаються **лише в оперативній пам'яті** під час поточного сеансу браузера. Після перезавантаження сторінки (F5) стан скидається до початкових 6 завдань із `src/data/tasks.js`, що повністю відповідає вимогам методички.
